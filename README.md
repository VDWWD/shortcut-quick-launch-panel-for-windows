A kind of Start Menu program for Windows where you can add shortcuts yourself so you can always open your most used program or website with one click.

More info: https://www.vanderwaal.eu/code-snippets/shortcut-quick-launch-panel-for-windows

&nbsp;

<img src="https://www.vanderwaal.eu/images/site/codesnippets/images/shortcut-quick-launch-panel-for-windows.png">



*Key features*

    Add a shortcuts to programs, files, websites or email addresses.
    Set your own icon for the shortcut, including the color of the button and icon.
    Set the color of the button and the icon per shortcut.
    You can define the number of columns, groups or button size.
    Tracks the number of click and date last used.
    Has a Dark Mode color scheme.
    Automatically adds icons based on their name.
